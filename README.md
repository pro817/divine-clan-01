# divine-clan-01

모바일 최적화 FPS 클랜전 스타일 테스트입니다.

## 포함 기능

- 닉네임 / 성별 입력
- 30문항 테스트
- 진행률 표시
- 이전 문항 이동
- 선택 답변 유지
- 결과 페이지
  - 캐릭터 이름
  - 유형명
  - 플레이 스타일
  - 성격/소통 성향
  - 캐릭터 해석
  - 인상적인 상황
  - 죽었을 때 상황
- 결과 공유

## 로컬 실행

```bash
npm install
npm run dev
```

## Vercel 설정

- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
